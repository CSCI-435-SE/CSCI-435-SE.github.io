# New-Tech Showcases

Twice in the semester, each team picks a modern software engineering tool that its project does not use yet, applies it to the project, and demos it live to the class in a **gallery walk**: six demo stations, one per team, with classmates rotating between them. Each team also submits a **tutorial video** and a short **handout**, so anyone can pick up the tool later.

Pick your tool from the [Showcase Tools](showcase-tools.md) list. See the [Syllabus](syllabus.md#11-project-structure-sprints-presentations-and-showcases) for how showcases count toward your grade.
