# CSCI 435 &mdash; Software Engineering Project Course

**William & Mary &middot; Fall 2026**

Welcome to CSCI 435. This semester, six teams will each work on a real, established open-source
project &mdash; not a toy assignment &mdash; using modern agentic AI tooling as part of a genuine
software engineering workflow: agile sprints, code review, CI, testing, and real project management.

!!! note "This is a proof-of-concept page"
    This site currently has two working sections &mdash; **Schedule** and **Projects** &mdash; built
    to test the W&M-themed MkDocs setup before the full course site (Assignments, Syllabus, Resources,
    Presentations) is filled in.
