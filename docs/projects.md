# Projects

Each team works on one of eight open-source projects, forked into the
[CSCI-435-SE](https://github.com/CSCI-435-SE) GitHub organization.

<div class="wm-card-grid" markdown="1">

<div class="wm-card">
<div class="wm-meta">Personal Finance</div>
<h3>Actual Budget</h3>
Local-first personal budgeting app &mdash; client-side SQLite over WASM with an optional sync server.
<br><strong>Stack:</strong> TypeScript, React
<br><a href="https://actualbudget.org/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/actual-budget">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">Design / Whiteboarding</div>
<h3>Excalidraw</h3>
Collaborative virtual whiteboard for sketching and diagramming, real-time multi-user editing.
<br><strong>Stack:</strong> TypeScript, React, Canvas
<br><a href="https://excalidraw.com/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/excalidraw">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">DevOps / Git Hosting</div>
<h3>Gitea</h3>
Lightweight, self-hosted Git service &mdash; a self-contained alternative to GitHub/GitLab.
<br><strong>Stack:</strong> Go
<br><a href="https://about.gitea.com/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/gitea">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">E-Commerce</div>
<h3>Medusa</h3>
Headless commerce platform &mdash; modular backend with a separate storefront and admin dashboard.
<br><strong>Stack:</strong> TypeScript, NestJS, React
<br><a href="https://medusajs.com/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/medusa">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">Customer Support</div>
<h3>Chatwoot</h3>
Customer engagement platform combining live chat, helpdesk, and omnichannel support.
<br><strong>Stack:</strong> Ruby on Rails, Vue.js
<br><a href="https://www.chatwoot.com/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/chatwoot">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">Community / Forum</div>
<h3>Discourse</h3>
Full-featured forum and online community discussion platform with a plugin architecture.
<br><strong>Stack:</strong> Ruby on Rails, Ember.js
<br><a href="https://www.discourse.org/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/discourse">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">Scheduling</div>
<h3>Cal.diy</h3>
Open-source scheduling and booking tool, MIT-licensed, in the same space as Cal.com.
<br><strong>Stack:</strong> TypeScript
<br><a href="https://www.cal.diy/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/cal.diy">Repository &rarr;</a>
</div>

<div class="wm-card">
<div class="wm-meta">Knowledge Base</div>
<h3>Outline</h3>
Team wiki and knowledge base with real-time collaborative editing.
<br><strong>Stack:</strong> TypeScript, Node, React
<br><a href="https://www.getoutline.com/">Website &rarr;</a> &middot; <a href="https://github.com/CSCI-435-SE/outline">Repository &rarr;</a>
</div>

</div>
